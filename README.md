# Word Guessing Game

A simple Word Guessing Game built with Python.

## Description

The Word Guessing Game is a command-line game in which the player tries to guess a hidden word. The game selects a word, and the player attempts to identify it by entering guesses.

This project was created for learning and practicing basic Python programming concepts.

## Features

- Random word selection
- Interactive user input
- Feedback on guesses
- Simple command-line interface

## Requirements

- Python 3.x

No external libraries are required.

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/MohammadMahdi-Hasani/word-guessing-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd word-guessing-game
   ```

3. Run the Python program:

   ```bash
   python src/main.py
   ```

## How to Play

1. Run the game.
2. Follow the instructions displayed in the terminal.
3. Enter your guesses to try to identify the hidden word.
4. Continue until you guess the word or the game ends.
